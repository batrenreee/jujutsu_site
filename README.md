# JJK Merkez

Jujutsu Kaisen evreni için hazırlanmış, mobil ve masaüstü uyumlu hayran bilgi merkezi.

## Canlı site

https://batrenreee.github.io/jujutsu_site/

## Özellikler

- Güncel ve kaydedilebilir haber merkezi
- Ayrıntılı karakter vikisi
- Cilt 0–30 manga kütüphanesi ve okuma takibi
- Karakter testi
- İki oyunculu veya CPU rakipli Lanet Düellosu
- Koyu, açık ve sistem temaları

Haber akışı GitHub Actions ile altı saatte bir güvenilir kaynaklardan güncellenir. Manga içerikleri uygulamaya kopyalanmaz; VIZ ve MANGA Plus gibi resmî okuyuculara bağlantı verilir.

Bu proje eğitim ve eğlence amaçlı, ticari olmayan bir hayran projesidir. Jujutsu Kaisen ile ilgili tüm haklar ilgili eser sahiplerine aittir.
